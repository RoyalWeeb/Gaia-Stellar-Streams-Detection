# Historical published-reference plan

Published-stream reference validation was removed from the project on
2026-10-29 at the user's request. The current CLI and candidate explorer do not
accept reference catalogs, calculate catalog overlap, or show a reference panel.
This file is retained so links from older project notes remain meaningful.

Earlier work explored acquisition of published DR3 memberships but did not ingest
a verified real member catalog or demonstrate known-stream recovery. Existing
reference-related files under older output folders are historical artifacts;
some are clearly labeled synthetic demonstration memberships. They are not
scientific confirmation of candidates.

The project still generates density candidates and supports physical follow-up.
Its current scientific limits are described in `DASHBOARD.md` and the README.
